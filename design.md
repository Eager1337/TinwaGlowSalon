# Tinwa Glow — Luxury editorial website

Approved direction: warm ivory #f7f4ed, aubergine #382431, gold #a68556, olive #73775d. Cormorant Garamond display and Manrope body. Oversized serif headlines, italic accents, tracked labels, fine borders, pill buttons. Asymmetric split hero with imagery sourced from the existing website; do not claim stock images show the actual salon.

Web only. Homepage: hero, services and filters, story, gallery, reviews, FAQ, visit details. Modal: selected service, preferred date/time, contact and consent; persist enquiry, then explicit WhatsApp handoff. No guaranteed appointments, invented prices, discounts, or availability.

Backend: oRPC enquiry create/list/update, Drizzle enquiries table, Better Auth Google/email owner sign-in. OWNER_EMAILS allowlist protects real enquiries. /studio uses labelled sample data only, /owner is private. Responsive navigation, accessible focus-trapped modal, loading/errors, reduced-motion, metadata and local SEO.

Research: existing website/service menu, Facebook and TikTok public search results, user's Maps excerpt. Hours conflict; ask customers to confirm by phone. Image reuse requires permission before launch.

## Brand & Colors

One token set, consumed per platform:

- **Web & desktop**: CSS variables in `packages/web/src/web/styles.css` (desktop loads the web UI).
- **Mobile**: `Colors.light` / `Colors.dark` in `packages/mobile/constants/theme.ts`, read via `useColors()`; `userInterfaceStyle: "automatic"` follows the system light/dark setting.

| mutedForeground | #737373 | #A3A3A3 | Secondary text |

## Architecture

- **API**: typed oRPC client (`lib/api.ts` in each package) → the backend in `@template/web`. Query/mutation hooks live in `queries/` (one file per feature); pages/screens call them with `@tanstack/react-query`.
- **State/sync**: TanStack Query with optimistic updates for instant-feel interactions.
- **Auth / payments / uploads**: see `skills/app/references/` when those features are needed.
